# Atoms - Éléments atomiques du CV

Chaque fichier JSON représente un élément réutilisable du CV.

## Structure

- **header/** : Informations de contact
- **titles/** : Titres de CV (différents selon le poste visé)
- **summaries/** : Résumés professionnels
- **education/** : Diplômes (un par fichier)
- **experience/** : Expériences professionnelles (une par fichier)
- **skills/** : Catégories de compétences
